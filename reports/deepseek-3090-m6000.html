DeepSeek on the RTX 3090 and the Quadro M6000

With the Maxwell build, DeepSeek runs on the M6000 alone or split across both cards. Using both is the fastest: 8.97 tokens a second, against 7.22 on the 3090 alone, and the M6000 alone 5.57. Per token, the M6000's own GPU work is about 5 times the 3090's, but on this PC every setup spends most of its time waiting for the CPU, so the M6000's extra 24 GB of graphics memory is worth more than its slowness costs.

What Maxwell support takes

  • A CUDA 12.x build (CUDA 13 cannot build for Maxwell) for both cards' architectures: -DCMAKE_CUDA_ARCHITECTURES="52;86" -DSTRATA_EXPERIMENTAL_SM60=ON.
  • The engine and setup accept compute capability 5.2 (they stopped at 6.0).
  • Maxwell-only versions of what the card lacks: packed FP16 math, the int8 dot product (__dp4a), and the tensor-core kernels (the plain kernels run instead).
  • The tensor-core choice is made per card, so a split of an old and a new card uses each card's own kernels.
  • Global loads cached in L1 (-Xptxas -dlcm=ca, on by default in a Maxwell build): Maxwell does not cache them otherwise, and the engine's weight reads depend on it.
  • The picture reader skips the M6000 and runs on the 3090.

All in github.com/Volko61/Strata, branch maxwell-sm52.

What to do next

  1. Use both cards. DeepSeek is set up for the app on the 3090 + M6000.
  2. Add RAM. Every setup spends most of each token waiting for the CPU, which reads experts from the SSD because 31 GB of RAM holds few of them. Setup recommends 64 GB for this model.
  3. Try other layer shares. The engine shares layers by free memory only. DS4_SPLIT sets the M6000's share by hand.
  4. Move the desktop off the M6000. It keeps the card busy before DeepSeek does anything.

How it was measured: each setup started the app's own server with the saved DeepSeek config (cards and flags changed), answered one warm-up request, then three to six timed answers to the same request while nvidia-smi, /proc/diskstats and /proc/stat were sampled every second. Speeds are the engine's own answer timing. PCIe counters are left out: the M6000 reports values far beyond its x4 link.
